# Análise Descritiva de Dados — PNAD 2015

Este projeto apresenta uma **análise descritiva de dados socioeconômicos da Pesquisa Nacional por Amostra de Domicílios (PNAD) 2015**, realizada a partir de microdados disponibilizados pelo Instituto Brasileiro de Geografia e Estatística (IBGE).

O objetivo é explorar estatisticamente variáveis demográficas e socioeconômicas da população brasileira por meio de técnicas de **estatística descritiva**, utilizando Python e suas principais bibliotecas para análise de dados.

---

## Tecnologias Utilizadas

- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  

---

## Objetivos da Análise

- Explorar a distribuição dos dados por meio de visualizações gráficas  
- Calcular e interpretar medidas de tendência central  
- Analisar medidas separatrizes (quartis e percentis)  
- Avaliar medidas de dispersão  
- Comparar variáveis socioeconômicas por características demográficas  

---

## Conjunto de Dados

Os dados utilizados neste projeto foram extraídos da **Pesquisa Nacional por Amostra de Domicílios – 2015 (PNAD)**, pesquisa realizada anualmente pelo IBGE com foco em aspectos como:

- Educação  
- Trabalho  
- Rendimento  
- Habitação  
- Condições socioeconômicas da população brasileira  

Fonte oficial dos microdados:  
https://ww2.ibge.gov.br/home/estatistica/populacao/trabalhoerendimento/pnad2015/microdados.shtm

---

## Variáveis Analisadas

As principais variáveis consideradas na análise foram:

- **Renda** — rendimento mensal do trabalho principal  
- **Idade** — idade do morador em anos  
- **Altura** — variável derivada (em metros)  
- **UF** — unidade federativa  
- **Sexo**  
- **Anos de Estudo**  
- **Cor ou Raça**

---

## Tratamento dos Dados

Antes da realização da análise, os dados passaram por etapas de limpeza e preparação, incluindo:

- Remoção de registros com renda inválida  
- Exclusão de valores ausentes  
- Seleção apenas da pessoa de referência de cada domicílio  

Esses procedimentos garantem maior consistência e confiabilidade nos resultados obtidos.
